# Sidewinder

משחק סנייק במדבר בלילה: 7 לוחות בסגנון נוקיה, מהירויות 1–9, שבעה בונוסים שמצטברים, חיפושית בונוס וקומבו. עובד במחשב (מקשי חצים / WASD) ובטלפון ובטאבלט (החלקה או כפתורי חצים), ואפשר להוסיף אותו למסך הבית.

## לוחות שיאים

- בלי לוח, השיא נשמר רק במכשיר. כשהמכשיר מחובר ללוח, **כל משחק שייך לשחקן**: אם אף אחד לא מחובר, Play פותח קודם את בחירת השחקן.
- **יצירת לוח**: בתפריט הראשי לוחצים על "Family leaderboard" ואז "Create a family board". כל לוח מקבל קוד אקראי בן 8 תווים. **מי שנוסף ראשון ללוח הוא ההורה שלו.**
- **הזמנה**: "Invite" שולח קישור בצורה `/?family=CODE`. הקישור פותח את הלוח במכשיר השני, ואפשר גם להקליד שם את הקוד.
- **PIN**: לכל שחקן יש קוד בן 4 ספרות. **במכשיר מחובר רק שחקן אחד בכל רגע.** כשעוברים לשחקן אחר (כפתור "Switch" או לחיצה על שם), מקישים את הקוד שלו, והשחקן הקודם מתנתק מהמכשיר. "Sign out" מנתק בלי להחליף.
- **הורה מול ילד**: כל אחד יכול להוסיף שחקן (ילד). רק הורה יכול להסיר שחקנים, לאפס PIN שנשכח ולהפוך שחקן אחר להורה. השרת בודק את כל זה, לא רק המסך. לוח תמיד נשאר עם הורה אחד לפחות.
- **לוח לחברים**: ילד מחובר לוחץ על "+ New board" ומסמן "Bring my scores". הוא נהיה ההורה של הלוח החדש, השיאים שלו מועתקים אליו, ומעכשיו **כל משחק שלו נספר בשני הלוחות**. חבר שפותח את קישור ההזמנה מוסיף את עצמו, ואם הוא כבר מחובר ללוח אחר, יכול ללחוץ על "Join as …" ולהביא את השיאים שלו.
- **שינוי PIN** ("Change my PIN") חל על כל הלוחות של אותו שחקן ומנתק את המכשירים האחרים שלו. **איפוס על ידי הורה** משנה את הקוד רק בלוח הזה, ומנתק את השחקן שם משאר הלוחות שלו. ככה הורה בלוח של חברים לא יכול להשתלט על שחקן בלוח של משפחה אחרת.
- אחרי 6 קודים שגויים השחקן ננעל ל-15 דקות.
- **ספירת משחקים**: כל משחק שנגמר נספר לפי מפה ולפי מהירות פתיחה (1–9). הטבלה נמצאת במסך הלוח, מתחת לשיאים.
- מגבלות ושמירה: עד 12 שחקנים בלוח. נשמרים שם, צבע, תפקיד, הקוד כ-hash, השיא לכל מפה ומספר המשחקים לכל מפה ומהירות. משחק שנגמר בלי אינטרנט עולה לשרת כשהחיבור חוזר.
- שחקן שנוצר לפני שהיו קודים: הקוד הראשון שמקישים עבורו הופך לשלו. בלוח שנוצר לפני שהיו הורים, השחקן הוותיק ביותר הופך להורה.

## מבנה

```
public/index.html  המשחק (קובץ אחד: HTML, CSS ו-JS)
public/sw.js       service worker: רשת קודם, עותק אחרון למשחק בלי אינטרנט
worker/index.js    ה-API של הלוח המשפחתי (Cloudflare Worker + D1)
wrangler.jsonc     הגדרות Cloudflare
```

המקור הוא ה-Artifact ב-Claude. ההבדלים: אין `window.claude`, יש לוח משפחתי, manifest, אייקונים ו-service worker.

### API

| בקשה | מה עושה |
|---|---|
| `POST /api/families` | `{ name }`: יוצר לוח ומחזיר `{ code, name }` (עד 10 בשעה לכל IP) |
| `GET /api/f/:code/players` | שם הלוח, השחקנים (`role`), השיאים (`b`) ומספר המשחקים לפי מפה ומהירות (`g`) |
| `PUT /api/f/:code/players/:id` | שחקן חדש `{ name, colour, pin }`, או `{ from: { code, id } }` עם ה-token של המקור כדי להצטרף עם השיאים. מחזיר `{ id, token, role }` |
| `POST /api/f/:code/players/:id/unlock` | `{ pin }`: מחזיר `{ token, linked }` (גם ל-tokens של אותו שחקן בלוחות אחרים) |
| `POST /api/f/:code/players/:id/games` 🔑 | `{ board, speed, score, level, len }`: סופר את המשחק בכל הלוחות של השחקן ושומר אם זה שיא |
| `POST /api/f/:code/players/:id/pin` 🔑 | `{ pin }`: הקוד שלי בכל הלוחות, ומנתק את שאר המכשירים |
| `POST /api/f/:code/players/:id/reset` 🔑👪 | `{ pin }`: הורה מאפס קוד לשחקן בלוח הזה |
| `POST /api/f/:code/players/:id/role` 🔑👪 | `{ role: "parent" \| "child" }` |
| `DELETE /api/f/:code/players/:id` 🔑👪 | מוחק שחקן מהלוח, עם השיאים, המשחקים והמכשירים |

🔑 = דורש `Authorization: Bearer <token>`. 👪 = ה-token חייב להיות של הורה באותו לוח.

## פרסום (Cloudflare Workers, חינם)

1. dash.cloudflare.com ← Workers & Pages ← Create ← Workers ← **Connect to Git** ← המאגר `sidewinder`.
2. Framework preset: **None**. Build command: ריק. Deploy command: `npx wrangler deploy`.
3. בפריסה הראשונה Wrangler יוצר לבד את מסד הנתונים `sidewinder-db`, והטבלאות נוצרות בבקשה הראשונה.

הכתובת: https://sidewinder.2sharp4u.workers.dev

**אם דחיפה ל-`main` לא מפעילה בנייה** (קרה בנובמבר 2026, כנראה כי לאפליקציית Cloudflare ב-GitHub אין גישה לריפו): ב-Cloudflare, sidewinder ← Settings ← Deploy Hooks יש hook בשם `claude-deploy` שבונה את `main`. בקשת POST לכתובת שלו מפעילה בנייה. התיקון הקבוע: ב-GitHub, Settings ← Applications ← Cloudflare Workers and Pages ← Configure, ולהוסיף את `sidewinder`.
